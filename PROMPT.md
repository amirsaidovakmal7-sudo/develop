**Этап 2. Технический SEO.**
- Серверные мета-теги для каждой страницы и языка, отдаваемые Django в исходном HTML, а не JS: `title`, `description`, `canonical`, `hreflang` (все языки и `x-default`), `og:*`, `twitter:*`, `lang` на `<html>`, `robots`. Источник текстов один: словари `i18n` — не заводи вручную вторую копию в Python, которая разойдётся с TS (например, скрипт при сборке выгружает мета в JSON, который читает Django). `DocumentMeta.tsx` после навигации должен давать то же самое.
- Превью ссылки: `og:image` и `twitter:image` с абсолютным https-адресом (`https://akmal.dev/static/…`), 1200×630 PNG (не SVG и не WebP — мессенджеры их не показывают), вес до ~300 КБ, `og:image:width/height/alt`, `og:type`, `og:site_name`, `og:locale` + `og:locale:alternate`, `twitter:card=summary_large_image`. Картинку сделай по дизайн-системе: фон `#050506`, шафран `#FFB829`, шрифт Inter Tight (файлы уже в `frontend/src/assets/fonts`), wordmark `akmal.dev`, короткий заголовок; по картинке на каждый язык. Сгенерируй через Puppeteer + sharp из HTML-шаблона, положи в `frontend/public`. Добавь `apple-touch-icon` 180×180 PNG, `theme-color`, при желании `site.webmanifest`.
- Структурированные данные JSON-LD, по одному блоку на страницу, в сумме: `Organization`/`ProfessionalService` (имя, url, areaServed, контакты из `contacts.ts`, `sameAs` — Telegram и Instagram), `WebSite`, `BreadcrumbList` на внутренних страницах, `Service` для услуг, `ItemList` для проектов. Только факты из этого промта. Цены, рейтинги, отзывы, FAQ-разметка без реального FAQ — запрещено.
- Заголовки: на каждой странице ровно один H1, логичная иерархия H2/H3, ключевая фраза в H1. Внешний вид заголовков не меняй (классы, размеры), меняй только текст и уровень тега, если это нужно.
- Решить дубли: `/about/` и `/about` (301 на вариант без слеша или canonical — выбери и обоснуй), `www`, `http`. Внутренние ссылки — настоящие `<a href>` (так сейчас), у языковых версий — полные ссылки с префиксом.

Узбекский — официальная латиница с `oʻ`, `gʻ` (U+02BB) и `ʼ` (U+02BC), как в текущем словаре, не ASCII-апострофы. **Этап 4. `sitemap.xml` и `robots.txt` через Django.**
- `django.contrib.sitemaps` входит в Django — устанавливать ничего не нужно, `requirements.txt` не меняй. Добавь `'django.contrib.sitemaps'` в `INSTALLED_APPS`.
- Опиши все страницы (5 страниц × языки по принятому решению). Для каждой — `<xhtml:link rel="alternate" hreflang>` на все языковые версии и `x-default`. Если на этапе остановки выбран вариант с префиксами, используй возможности `Sitemap` с `i18n`/`alternates` или соберите ссылки вручную — как получится надёжнее.
- **Ловушка:** без `django.contrib.sites` Django берёт домен из заголовка Host запроса, на PythonAnywhere он может оказаться `develop.pythonanywhere.com`. В sitemap должен всегда быть `https://akmal.dev`, независимо от Host: возьми домен из настройки (переменная окружения с запасным значением `https://akmal.dev`), без БД и миграций. `lastmod` — только настоящая дата, иначе не указывай.
- `robots.txt` — обычный текстовый ответ из Django: `User-agent: *`, `Allow: /`, `Disallow: /admin/`, `Disallow: /order`, `Sitemap: https://akmal.dev/sitemap.xml`. **Каталог `/static/` не закрывай**, иначе поисковик не загрузит CSS и JS и не отрисует страницу.
- Маршруты подключи в `project/urls.py` (там сейчас `admin/` и `include('app.urls')`), чтобы они не конфликтовали с маршрутами приложения и с `handler404`.
